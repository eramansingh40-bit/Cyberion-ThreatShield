10. Root Cause

The alert was generated by a controlled SOC lab/test command designed to simulate suspicious login-related activity:

Write-Output 'Suspicious Login Activity Test - Event ID 4625'

The actual telemetry captured was Sysmon Event ID 1, indicating PowerShell process creation. The command text referenced Event ID 4625 but did not itself generate a Windows authentication failure event.

Therefore, the root cause was controlled security testing of PowerShell/Wazuh detection, rather than confirmed malicious authentication activity.
